**Way to City** is a modern, high-performance web platform designed to streamline urban travel and navigation in major global destinations. It bridges the gap between airport arrivals and city transit systems by providing curated, actionable guides on airport-to-city connections, local public transit cards, top cultural landmarks, authentic cuisine, and interactive map exploration.

---

## 🌟 Key Features

- **✈️ Airport-to-City Navigation:** Detailed breakdowns of rail, express bus, metro, and taxi transit routes from international airports directly into city centers.
- **💳 Public Transit Pass & Fare Intelligence:** Practical instructions on purchasing transit cards, reload policies, fare structures, and zone rules.
- **🗺️ Interactive Web GIS Mapping:** Integrated Leaflet & React-Leaflet maps highlighting points of interest, key stations, and transit corridors.
- **🌍 Filter by Continent & Country:** Real-time search and filter UI enabling seamless navigation across hundreds of destinations.
- **⚡ Next.js 16 App Router & Server Components:** Ultra-fast page loads, incremental revalidation, and edge caching.
- **🎨 Modern Glassmorphic UI:** Built with **Tailwind CSS v4**, **React 19**, and **Lucide React** icons.
- **📈 Structured SEO & Metadata:** Automated JSON-LD schema injection for optimal search engine indexing.

---

## 🏗️ Architecture & Tech Stack

- **Framework:** Next.js 16.3 (App Router, Server-Side Rendering & ISR)
- **Library:** React 19 & React-DOM
- **Language:** TypeScript 5.7
- **Styling:** Tailwind CSS v4, PostCSS, Lucide React
- **Maps:** Leaflet & React-Leaflet
- **Data & Backend:** Supabase JS Client, Google Sheets API sync
- **Deployment:** Vercel with Edge Network & Vercel Web Analytics

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- pnpm (recommended) or npm / yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/rerendurgut/way-to-city.git
cd way-to-city

# 2. Install dependencies
pnpm install

# 3. Start local development server
pnpm dev
```

Visit `http://localhost:3000` in your browser.
